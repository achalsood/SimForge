# SimForge v0.1.0

First public Windows x64 release. **Prepared locally; publication awaits explicit owner approval.**

## Highlights

- Interactive Vulkan warehouse simulation and operational metrics.
- Deterministic simulation, replay and snapshots within documented platform assumptions.
- Seeded stochastic demand, historical demand calibration and model diagnostics.
- Paired multi-seed experiments, sensitivity and interaction studies, and independent confirmation.
- Checkpoint intervention comparisons with matched control/intervention playback.
- Persistent projects, Study History and renderer-independent command-line experiments.

## Requirements

Windows x64, Microsoft's x64 Visual C++ v14 Redistributable 14.51.36231 or later, and a compatible Vulkan graphics driver. Local validation uses Windows 11 Home 26H2 (26300.9711) and an NVIDIA GeForce RTX 5080 Laptop GPU; other configurations are unverified.

Vulkan 1.1, swapchain support and KHR or EXT swapchain-maintenance1 presentation fences with corresponding instance extensions are required. Vulkan 1.1 alone is insufficient. The installed Intel driver lacks the required presentation fences. See [Windows requirements and troubleshooting](../windows-release.md) and [Microsoft's runtime download page](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170). No SDK or compiler is required to run the package.

## Installation and first run

Download `SimForge-v0.1.0-windows-x64.zip`, extract all files, and launch **simforge_sandbox.exe**. Click **Open warehouse workspace** to use the supplied baseline, then select **Simulation**. Play/Pause, Step, Reset and speed controls operate the model. The package includes bottleneck and seeded Poisson examples, a checkpoint study request, and `docs/windows-release.md`. Save a new project to a writable location using File > Save Project As.

## Known limitations

- Separate clean-machine Vulkan testing is unavailable; extracted-package checks on the development host do not establish that coverage.
- The unsigned first release has no installer or automatic updater. Microsoft runtime and graphics-driver prerequisites are installed separately.
- Cross-platform bitwise determinism is not promised; seeded generation/replay retain documented version and platform assumptions.
- Checkpoint studies admit at most 66 positive-intensity Poisson seeds under the conservative 20-million-arrival execution budget; other replication plans allow up to 100 distinct seeds when budgets permit. Existing project/evidence storage limits remain enforced.
- Statistical intervals and simulation outcomes are conditional on model and sampling assumptions, not guarantees of real operational results.
- Device/surface-loss recovery is not implemented. Other GPUs, Windows versions, split graphics/presentation queues and non-Windows platforms are unverified.

## Integrity and source

Compare the ZIP's SHA-256 with `SimForge-v0.1.0-SHA256.txt`. The exact source commit and per-file hashes are in `build-info.json` and `package-inventory.json` inside the package. The packaging script generates an adjacent `release-receipt.json` and `github-release-body.md` containing the exact source link, ZIP byte count and checksum. Those values are generated after archiving to avoid embedding an archive's own checksum in itself.
